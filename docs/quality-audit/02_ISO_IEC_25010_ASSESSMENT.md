## Safety applicability

AssocMap stores organizational records and geographic information; no inspected route/mobile code controls hazardous machinery, clinical decisions or emergency equipment. Wrong membership, reports, locations, confidential publication or record loss are consequential **data-quality/security/reliability risks**. They are not automatically formal functional-safety hazards. The two Not applicable rows describe physical safe-state/alert functionality in this current scope. If these records become inputs to safety-critical operations, obtain a hazard analysis and revise applicability with the owner/adviser. Neither mathematical geometry validity nor a database transaction certifies safe real-world decisions.
